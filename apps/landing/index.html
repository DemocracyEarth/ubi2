Proof of Humanity

Being human is the
only requirement

No biometrics. No government ID. No surveillance database. Verification is probabilistic and adversarial — it degrades safely, denying on uncertainty rather than guessing.

01

Social Vouching

Existing verified humans vouch for new applicants. Each vouch is a signed on-chain transaction — MetaMask-signable, no bespoke tooling.

02

AI Liveness Challenge

An LLM generates and grades liveness + interaction challenges, resistant to replay attacks and bots. Behavioral signals are combined — no single hard gate that excludes.

03

Quorum Verdict

Independent verifier nodes each run their own AI backend at temperature 0 with a canonical structured output. A supermajority must agree before anyone is admitted — no single node decides who is human.

04

Soulbound NFT

A verified human receives a non-transferable Proof-of-Humanity NFT. The NFT is the credential for streaming UBI, for joining the validator set, and for voting in governance.

Verified Pending AI Juror
Safe degradation invariant: New claims are denied on uncertainty; established humans are revoked only by quorum + appeal. Disputes go to a jury of verified-human AI-nodes. Bots and duplicates fail closed.

Prompt Contracts

Write intent.
AI executes it.

Smart contracts are written in natural language and executed by a quorum of AI interpreter nodes. If the quorum agrees on the effect, it commits. If they disagree, the contract aborts — no partial state, ever. Intent-as-law, not code-as-law.

Example Prompt Contract
"Transfer 50 UBI from the escrow to Alice if and only if she has submitted proof of completing the agreed task by Friday, as attested by at least two of the three designated witnesses. Otherwise, return the funds to the depositor."

On disagreement: abort deterministically — escrow untouched, no partial state.

Deterministic inference

Temperature 0, pinned model, canonical structured-output schema. Two independent nodes interpreting the same contract produce the same canonical effect — or neither commits.

Multi-interpreter quorum

N independent nodes each interpret the contract; the effect (state delta) commits only when a supermajority produce the same canonical output. No single node executes alone.

Least authority

A prompt contract gets only the state and authority it was explicitly granted. Injection attempts fail closed — the quorum aborts, never executes malicious intent.

Anyone can write one

No Solidity. No ABIs. If you can state your intent in plain language, you can deploy a contract. The AI layer translates intent to a bounded, formally-safe effect language.

How the Network Works

AI is non-deterministic.
Consensus must not be.

The hardest problem: make a network of AI-backed nodes agree on state, reliably, without any single point of control. The solution is elegant: contain non-determinism below the consensus line, expose only a canonical effect agreed by a supermajority.

I1

Deterministic consensus over non-deterministic AI

Every LLM verdict runs at temperature 0 with a pinned model and emits a canonical, structured output. The network commits the effect — a state delta — only when an independent quorum of N interpreters produce the same canonical effect. On disagreement, the operation aborts deterministically.

I2

Reproducible time-based balances

Streaming emission (1 UBI/hour), demurrage, and stream flows are pure functions of (state, timestamp). Integer arithmetic only — no floats on any consensus path. Two nodes computing a balance at the same timestamp agree to the smallest unit.

P2P

Real peer-to-peer networking

libp2p transport (Noise/TCP/Yamux), gossipsub on two topics (transactions + blocks), request-response block sync. A fresh node syncs from genesis to the tip, re-executes every block, and must reach a byte-identical state root — or the sync is rejected.

PoA

Proof of Authority, round-robin

Validators are PoH-verified humans. Block production rotates round-robin; if the current proposer misses its slot, the remaining nodes elect the next validator deterministically within 3 timeouts. The chain is live while a majority of validators are alive.

Followers re-execute every block and compare state roots byte-for-byte. A block whose state root differs from the re-execution is rejected — the proposer cannot smuggle in divergent state.
